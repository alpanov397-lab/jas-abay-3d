# Jas Abay мектебі — 3D демо (1-кезең)

Браузерде ашылатын, нөлден жасалған 3D демо. Ойыншы аулада бастайды, негізгі есіктен кіріп,
кіреберіс залы → турникет → холл → Абай суреті бар баспалдақ арқылы 2-қабаттағы мұғалімдер
бөлмесіне дейін жетеді және бес кітапты жинайды.

## Қалай ашу керек
`index.html` файлын екі рет бас (Chrome/Edge). three.js интернеттен жүктеледі, сондықтан интернет керек.

Басқару: **WASD** — жүру, **тінтуір** — қарау, **E** — кітап алу / есік ашу, **Shift** — жүгіру,
**V** — камера (артынан / бірінші жақтан), **Қайта бастау** батырмасы — басынан.

## Файлдар
| Файл | Не үшін |
|---|---|
| `layout.js` | **Мектептің деректері** — бөлмелер, есіктер, түстер, кітаптардың орны, өлшемдер. Көбіне тек осыны өңдейсің. |
| `world.js` | Едендер, баспалдақ, қабырғалар, коллизия (ойыншы қабырғадан өтпейді). |
| `game.js` | 3D графика, жиһаз, фасад, кейіпкер, камера, HUD. |
| `online.js` | Тіркелу, онлайн кейіпкерлер, достар, ауладағы кітапхана, шайхана чаты, деңгей мен ортақ мақсат. |
| `index.html` | Бет, батырмалар, қазақша санағыш. |

## Жиі өзгертетін нәрселер (layout.js)
- **Бөлменің орнын ауыстыру:** `rooms` ішінде `x0`, `x1` (солдан оңға метрмен) және `side` ('front' — аула жақ, 'back' — артқы жақ).
- **Есікті ауыстыру:** `doorX`; ашық тұруы — `open: true`; мүлде ашылмауы — `locked: true`.
- **Жиһаз жиынтығы:** `type` (classroom, teachers, office, library, canteen, lab, medical, psychology).
- **Кітаптар:** `books` ішінде `x`, `z`, `y` (y = еден биіктігі + 0.8).
- **Түстер:** `colors` (қызғылт сары, көк, кірпіш, бомбер т.б.).

## Болжам өлшемдер (нақтылау керек)
Ғимарат 36×14 м · дәліз ені 2 м · орталық холл ені 9 м · қабат биіктігі 3.4 м ·
1-қабат едені ауладан 0.75 м жоғары · кіреберіс холлдан 0.3 м төмен (2 саты) ·
баспалдақтың әр сатысы 1.5 м ені, 3.1 м ұзындығы, 11 баспалдақ.

## Абай портреті
Қазір портреттің орнында жазуы бар тақта тұр. Нақты муралдың фотосын қою үшін
`game.js` ішіндегі `TX.abay` текстурасын фотомен ауыстыру керек (келесі қадамда бірге жасаймыз).

## Тексеру
`node test/route.test.js` — ауладан мұғалімдер бөлмесіне дейінгі маршрутты және қабырға/қоршаудан өтпеуді тексереді.

## Онлайн мүмкіндіктер (2–4 кезең)
claude.ai бетінде ашылғанда: кейіпкерлер бір-бірін нақты уақытта көреді (аты, рөлі, деңгейі, «Кітап оқып отыр» күйі),
профиль, бетбелгі, жетістіктер мен достар қайта кіргенде сақталады, шайхана чаты бәріне ортақ.
Файлды компьютерден ашсаң — «жалғыз режим»: бәрі жұмыс істейді, бірақ деректер тек сол браузерде сақталады.

- **Ауладағы кітапхана** (сол жақтағы көк павильон): E — отырып кітап оқу, қай бетте тоқтағаның сақталады. Кітаптар `layout.js` → `readingBooks`.
- **Шайхана** (оң жақтағы киіз үй): E — чат. Әр хабарламада: 🔇 дыбысын өшіру, ⛔ бұғаттау, ⚑ шағым. Модератор (бет иесі және расталған мұғалім) 🗑 өшіре алады.
- **Tab** — мектептегі адамдар: достық сұрауы, қабылдау; бет иесі мұғалімдерді растайды.
- **Деңгей**: кітап табу +20 XP, оқылған әр жаңа бет +5 XP, жетістік +10 XP; 100 XP = 1 деңгей.
- **Ортақ мақсат**: түлек пен кәсіпкер шайханада «+1 кітап» басады (сынақ ұпайы). 20-ға жеткенде кітапханада жаңа сөре ашылады.
- «Басып тұрып сөйле» — дауыс үшін жеке сервер керек (келесі кезең). Нақты Kaspi төлемі — мектеппен келісілгеннен кейін.

## Графика және жаңа мүмкіндіктер (5-кезең)
- **Фотореалистік рендер:** PBR материалдар (MeshStandard), sRGB түстер, ACES тон-маппинг, аспаннан шағылыс ортасы (PMREM) — әйнек пен металл айналаны шағылыстырады.
- **Күн:** тәулік уақытына қарай бағыты мен түсі өзгереді; жұмсақ көлеңке камерасы кейіпкердің соңынан жүреді.
- **Текстуралар:** кірпіш, бетон, тас төсеніш, шөп, мата, джинсы, қабық — бәрі бедерлі (normal map), сырттан жүктелмейді.
- **Модельдер:** бұтақты ағаштар, туя, жапырақты бұталар; көлемді терезе жақтауы мен тұғыры; жұмыр тұтқа мен жоңғыланған баллюстрада; жұмыр бағаналы металл қоршау.
- **Кейіпкер:** ұл/қыз, ≈7.5 бас пропорция, тізе/шынтақ буындары, бет-әлпет, саусақтар, шаш; бірқалыпты жүру және жүгіру (Shift / 🏃).
- **Аула:** 50 орындық кітапхана (отырғанда бас үстінде шырақ, қолда кітап аты), киіз үй шайхана, бас үстінде аттар.
- **Телефон:** 16:9 көлденең, джойстик пен батырмалар. **Баптаулар:** сапа, уақыт, сезімталдық. **Нұсқаулық:** ❔ батырмасы.
- Жаңа файлдар: `env.js` (аспан, уақыт, сапа, нұсқаулық), `yard.js` (кітапхана мен шайхана), `mobile.js` (сенсорлық басқару).

## Тіркелу және кітапхана (6-кезең)
- Тіркелу: аты-жөні (аты және тегі), телефон (+7), рөл (түлек болса — бітірген жылы), ұл/қыз, профиль фотосы (96×96-ға кішірейтіледі).
- Телефон тек ойыншының жеке профилінде (`data/users/<id>/profile`) сақталады; ортақ `people` тізіміне жазылмайды.
- Кітапханада отырар алдында кітап атауы мен авторы толтырылады. Бас үстінде: фото, аты-жөні, рөлі, «кітап атауы» және оқу уақыты. Тұрғанда оқу тарихына (`readLog`) жазылады.

## Дайын 3D модельдер (7-кезең)
`assets/` ішінде — ықшамдалған модельдер (`props-data.js`) мен текстуралар; `props.js` оларды жүктеп, орнына қояды
(компьютер жиынтығы, орындық, жасыл тақта, сағат, гүл, қоқыс жәшігі, су құйғыш, шам, папка, ағаштар, шөп, саябақ орындығы, көше шамы).
Модельдер жүктелмесе, ойын бұрынғы қарапайым заттармен жұмыс істей береді.

## 8-кезең
- `school.js`: Құндыз апай (ресепшн, Claude арқылы жауап береді; қолжетімсіз болса — кілт сөз бойынша), әкімші бөлімі 🛠 (статистика, Құндыз апай мәліметтері, хабарландыру, ортақ мақсат).
- Деңгей — оқу минутымен (әр 30 мин). 5 кітап тапсырмасы өшірілді. Кітапхана жанында ТОП-10 оқырман тақтасы.
- Қызыл орындықтарға отыруға болады. Жыл мезгілдері мен ауа райы (env.js): қар, жаңбыр, күзгі жапырақ.

## Claude-сыз сайт ретінде іске қосу (Firebase + Netlify) — 9-кезең
Ойын енді кәдімгі сайтта да жұмыс істейді: тіркелу, онлайн ойыншылар, чат, статистика, әкімші бөлімі — бәрі тегін Firebase арқылы.
Claude ішінде (claude.ai) бұрынғыдай жұмыс істей береді. Файлдар: `config.js` (баптау), `fb.js` (адаптер), `firebase/` (қауіпсіздік ережелері).

1. https://console.firebase.google.com → **Add project** → атауы `jas-abay` (Analytics керек емес).
2. **Authentication** → Get started → Sign-in method: **Anonymous** және **Email/Password** қосу. Users → **Add user**: әкімші email мен құпия сөз.
3. **Firestore Database** → Create database → орны: europe-west → production mode. **Rules** қойындысына `firebase/firestore.rules` мәтінін қой (ADMIN_EMAIL орнына өз email-ің) → Publish.
4. **Realtime Database** → Create database → Belgium (europe-west1) → locked mode. **Rules** қойындысына `firebase/database.rules.json` мәтінін қой → Publish.
5. ⚙ Project settings → Your apps → **Web (</>)** → тіркеу → `firebaseConfig` объектісін көшіріп, `config.js` ішіндегі `firebase: null` орнына қой. `adminEmail` — 2-қадамдағы email.
6. https://app.netlify.com/drop → `jas-abay-3d` папкасын сүйреп таста → сайт сілтемесі шығады.
7. Firebase → Authentication → Settings → **Authorized domains** → Netlify доменін қос (мысалы `jas-abay.netlify.app`).
8. Әкімші ретінде кіру: `сайт-сілтемесі/#admin` → email + құпия сөз. 🛠 батырмасы тек саған шығады.

Ескерту: тегін Spark жоспарында Firestore — тәулігіне ~50 000 оқу / 20 000 жазу, Realtime Database — бір мезгілде 100 адам.
Сайтта Құндыз апай Claude-сыз жұмыс істейді: әкімші енгізген мәліметтерден кілт сөз бойынша жауап береді.
